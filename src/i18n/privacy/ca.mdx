## Dades que recollim

Aquest lloc web no utilitza eines d'analítica, publicitat ni seguiment dels visitants.

Les úniques dades personals que podem recollir són les que ens facilitis voluntàriament quan contactis amb nosaltres, per exemple el teu nom, correu electrònic, número de telèfon i el contingut del missatge.

## Finalitat del tractament

Les dades facilitades s'utilitzaran exclusivament per atendre les teves consultes, sol·licituds d'informació, reserves o qualsevol altra petició relacionada amb els serveis del restaurant.

Les dades no s'utilitzaran amb finalitats publicitàries ni comercials diferents de les indicades sense el teu consentiment.

## Base jurídica

La base jurídica del tractament és la gestió de la sol·licitud realitzada per la persona interessada i, quan correspongui, l'aplicació de mesures precontractuals sol·licitades per aquesta.

## Destinataris de les dades

No cedirem les teves dades personals a tercers, excepte quan existeixi una obligació legal o quan sigui necessari comptar amb un proveïdor de serveis per poder gestionar la teva sol·licitud.

En aquest últim cas, el proveïdor tractarà les dades únicament d'acord amb les instruccions del responsable i amb les garanties exigides per la normativa de protecció de dades.

## Conservació de les dades

Les dades es conservaran durant el temps necessari per gestionar la teva consulta, reserva o sol·licitud i, posteriorment, durant els terminis necessaris per complir les obligacions legals que puguin correspondre.

## Drets de les persones interessades

Pots exercir els teus drets d'accés, rectificació, supressió, oposició, limitació del tractament i, quan correspongui, portabilitat de les teves dades.

Per exercir aquests drets pots contactar amb nosaltres a:
<a href={`mailto:${props.business.email}`}>{props.business.email}</a>.

També tens dret a presentar una reclamació davant l'Agència Espanyola de Protecció de Dades (AEPD) si consideres que el tractament de les teves dades personals no s'ajusta a la normativa aplicable.

## Enllaços a serveis externs

Aquest lloc web pot contenir enllaços a serveis externs com Google Maps, xarxes socials o altres llocs web de tercers.

En accedir a aquests enllaços abandonaràs aquest lloc web i quedaràs subjecte a les condicions i polítiques de privacitat del servei corresponent.

## Canvis en aquesta política

Aquesta política de privacitat es podrà actualitzar quan sigui necessari per adaptar-la a canvis en el funcionament del lloc web o en la normativa aplicable.
